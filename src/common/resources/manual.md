## 💬 1. 聊天功能
想要和我聊天或者问我问题，只需要在消息中**艾特我**，或者使用我的**召唤咒语**：

- **召唤咒语**：在消息开头加上 `miku,` 或者在末尾加上 `,miku`
- **提示**：不管是中英文逗号，还是 `Miku` 大小写，我都能感应到哒！

> **例：**
> `Miku, 今天的心情怎么样？`
> `给我唱首歌吧，miku`

## 🎵 3. Arcaea 表情包工坊
制作 *Arcaea* 风格的角色表情包！

#### ⚡ 基础指令
- `arc <角色> <文字>`：最快生成方式！
- `arc`：进入交互模式（新手推荐，我会一步步问你）
- `arc -h`：查看简略帮助
- `arc帮助`：查看带图的精美帮助

#### 🎨 进阶参数（老手专用）
如果你想精确控制每一个细节，可以在指令后面加上这些参数：

| 参数 | 说明 | 范围 | 默认值 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| `-s` | 文字大小 | 20~45 | 35 | 数字越大字越大 |
| `-x` | 横向位置 | 0~296 | 148 | 0=左, 296=右 |
| `-y` | 纵向位置 | 0~256 | 128 | 0=上, 256=下 |
| `-r` | 旋转角度 | ±180 | -12 | 负数=逆时针 |
| `-c` | 文字颜色 | HEX | 默认 | 如 `ff0000` |

## 📓 4. 群聊小本本 (黑历史)
Miku 会悄悄记下大家的名言（暴言）哦！(¬‿¬)

### 📸 记录名言
当群里有人说了什么不得了的话：
- **操作**：**引用 (回复)** 那条消息。
- **发送**：`入典`、`记`、`记仇`、`📸` 或 `📝`。
- **效果**：Miku 会把这句话永久保存在小本本里！

### 🎲 随机回顾
想看看以前大家说过什么怪话？
- **方法一**：发送以下任意指令：
    - `黑历史`、`语录`、`来点语录`、`随机黑历史`
    - `翻翻小本本`、`随机迫害`、`抽黑历史`
- **方法二**：双击头像 **戳一戳 Miku**。
- **效果**：随机抽出一条黑历史“公开处刑”！

## 📺 5. B站视频笔记
太长不看？让 Miku 帮你总结视频内容吧！

### 📝 生成笔记
Miku 现在学会了用不同的角度看视频哦！请根据视频类型选择指令：

- **基础指令**：`/笔记 <视频链接> [模式]` (默认模式为知识总结)

| 模式 | 适用场景 | 示例 |
| :--- | :--- | :--- |
| **默认** | 知识、教程、新闻 (严肃总结) | `/笔记 https://...` |
| **音乐** | MV、翻唱、演奏 (歌词与情感) | `/笔记 https://... 音乐` |
| **搞笑** | 鬼畜、整活、相声 (梗与笑点) | `/笔记 https://... 搞笑` |
| **剧情** | 游戏剧情、动画解说 (故事梳理) | `/笔记 https://... 剧情` |

> **提示**：也可以使用 `/summary` 代替 `/笔记` 哦。
> **注意**：生成需要几分钟时间，请耐心等待，不要催 Miku 啦 ♪

### 📂 记忆回廊 (笔记列表)
想找回以前生成的笔记？
- **指令**：`/笔记列表`、`/bilidoc` 或 `/doc_list`
- **功能**：查看所有已生成的笔记列表，并可以再次提取下载哦！

## 📰 6. 每日新闻
Miku 可以帮你获取最新的新闻汇总哦！( •̀ ω •́ )✧

- **指令**：`/news [偏移量] [summary]`
- **别名**：`/新闻`, `/news 总结`
- **功能**：生成并发送新闻汇总 PDF 文件。如果加上 `summary` 或 `总结`，还会呼叫 AI 对热搜标题进行智能分析哦！

**参数说明**：
- 不带参数：获取**今天**的新闻。
- `-1`：获取**昨天**的新闻。
- `summary` / `总结`：让 Miku 读一遍新闻标题并写一份“太长不看”版总结。

**交互模式**：
觉得 PDF 太长不想看？
1. 发送 `/news summary` 直接获取总结。
2. 或者，在 Miku 发送 PDF 后，**引用（回复）** 那条文件消息，发送 `总结` 或 `summary`，Miku 也会补上一份分析报告哒！

> **例：**
> `/news` -> 今天的热点是什么？
> `/新闻 -1` -> 昨天发生了什么大事？
> `/news 总结` -> 既要看图，也要看 AI 划重点！
