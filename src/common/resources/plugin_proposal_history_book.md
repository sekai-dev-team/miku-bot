# 📖 插件提案：群友黑历史本 (History Book)

## 🎯 核心目标
记录群友的“暴言”、“搞笑发言”或“Flag”，并在合适的时机（或被动触发时）随机吐出一条，公开处刑。

## 🛠️ 交互设计 (优雅版)

为了适应群聊的快节奏，本插件采用**“无感触发”**与**“自然交互”**的设计理念。

### 1. 📝 记录黑历史 (Record)
*   **核心交互**：**引用（Reply）**目标消息 + **短语/Emoji**
*   **触发词**：
    *   `记` / `记仇` / `入典`
    *   `📸` (相机Emoji) / `草` (可选)
*   **逻辑**：只有在**回复某条消息**时，这些短词才生效。平时单独发送不会触发，避免误触。
*   **Miku 反应**：
    *   “📸 咔嚓！已记录在案~”
    *   “✍️ 这种话也敢说，我记下来了！”

### 2. 🎲 随机处刑 (Random Review)
*   **方式一：戳一戳 (Nudge)**
    *   **动作**：双击（戳一戳）群里的 Miku 头像。
    *   **效果**：Miku 随机丢出一条黑历史。
*   **方式二：自然指令**
    *   **指令**：`来点语录` / `翻翻小本本` / `随机黑历史` / `随机迫害`
    *   **无需前缀**：直接发送即可。

### 3. 🔍 定向查询 (Targeted)
*   **指令**：`查成分 [at某人]` / `查语录 [at某人]`

### 4. 🗑️ 销毁证据 (Delete)
*   **指令**：`miku 删 [ID]` (保留一点仪式感，防止误删)

---

## 💾 数据库模型 (SQLite)

使用 `nonebot-plugin-localstore` 提供的路径存储 `history.db`。

**表名：`group_history`**

| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `id` | INTEGER PK | 自增主键 |
| `group_id` | TEXT | 群号 |
| `user_id` | TEXT | 发言者 QQ |
| `user_name` | TEXT | 记录时的昵称 |
| `content` | TEXT | 内容 (支持纯文本或 CQ码) |
| `msg_type` | TEXT | 类型 (text/image) |
| `timestamp` | INTEGER | 记录时间 |
| `recorder_id`| TEXT | 记录者 QQ |

## 🎨 交互流程示例

**场景 A：光速记录**
> **User A**: 我永远喜欢花田十辉！
> **User B** (回复 A): 📸
> **Miku**: 📸 咔嚓！User A 的暴言已永久入典！

**场景 B：无聊摸鱼**
> *(User C 双击了 Miku 的头像)*
> **Miku**: 既然你戳了我，那就让你看看这个！
> 📅 **2024-12-28**
> 👤 **User A** 说：
> “我永远喜欢花田十辉！”

**场景 C：高清重制 (Phase 3)**
> **User D**: 来点语录
> **Miku**: *(发送一张精美的黑白滤镜图片)*
> *“ 这里的空气，充满了大葱的味道。”*
> —— User E, 2025年

## 🚀 开发计划

1.  **Phase 1 (基础)**: 实现“回复记录”和“戳一戳/指令回顾”，使用 SQLite 存储。
2.  **Phase 2 (多媒体)**: 记录图片消息（保存 Image ID 或下载图片）。
3.  **Phase 3 (图片化)**: 使用 `htmlrender` 将语录渲染为“名人名言”风格图片。
