# 1. 💬 核心对话 (Chat)
Description: 基础对话、AI 聊天与系统状态

💬 **核心对话功能**
------------------
**1. 智能聊天**
   - 召唤: `Miku, <内容>` 或 `<内容>, Miku`
   - 例: `Miku, 今天天气怎么样？`

**2. 系统指令**
   - `/stat`: 查看服务器状态 (CPU/内存/群组)
   - `/help`: 召唤此帮助菜单
   - `/help <序号>`: 直接查看对应功能详情

# 2. 📰 新闻聚合 (News)
Description: 每日热点、热搜搜索

📰 **新闻聚合功能**
------------------
**1. 获取日报**
   - `/news`: 获取今日新闻汇总 (PDF)
   - `/news -1`: 获取昨天的新闻

**2. 热搜搜索**
   - `/news search <关键词>`
   - 例: `/news search 科技`

**3. 智能总结**
   - 在收到 PDF 后，回复消息并发送 `summary` 或 `总结`，
     可以让 AI 帮你划重点哦！

# 3. 📈 股市看板 (Stock)
Description: 实时股价、大盘复盘与研报

📈 **股市看板功能**
------------------
**1. 基础查询**
   - `/stock` (或 `/股票`): 查看今日A股涨幅榜
   - `/stock <代码/名称>`: 查询个股实时行情
   - 例: `/stock 300750` 或 `/stock 宁德时代`

**2. 深度分析**
   - `/stock review`: 获取今日大盘复盘简报
   - `/stock report`: 获取AI生成的深度研报

# 4. 📺 B站笔记 (BiliNote)
Description: 视频内容一键总结

📺 **B站笔记助手**
------------------
**1. 生成笔记**
   - `/笔记 <链接> [提示词类型]`
   - 例: `/笔记 https://b23.tv/...` (默认)
   - 例: `/笔记 https://b23.tv/... 搞笑` (指定类型)

**2. 笔记管理**
   - `/笔记列表`: 查看并下载历史生成的笔记
   - `/笔记提示词`: 管理自定义提示词 (list/add/del/view)

# 5. 📓 群聊黑历史 (History)
Description: 语录记录与随机回顾

📓 **群聊黑历史**
------------------
**1. 记录名言**
   - 引用某人的消息，发送 `入典`、`记` 或 `📸`

**2. 随机回顾**
   - 发送 `随机黑历史`、`语录` 或 `翻翻小本本`
   - 双击(戳一戳) Miku 的头像

# 6. 🛠️ 管理员 (Admin)
Description: 系统配置与维护 (仅限超管)

🛠️ **管理员指令**
------------------
**1. 资源管理**
